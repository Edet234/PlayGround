How the live connection works

Production mode opens a persistent WebSocket to the platform's tokenized ssgportal.com/*.aspx endpoint (see URL above). This demo runs a SimulatedSocket with identical events (round_start → tick → round_end) and identical signal processing, so you can see zero-latency alerts in action. Paste a live tokened link to switch from simulation to real data. Tokens expire — the engine watches heartbeats + TTL and raises TOKEN EXPIRED / CONNECTION LOST immediately.
